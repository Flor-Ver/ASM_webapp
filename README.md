# Streamlit-webapp: asynchrone machine

## Starten

Open een terminal in deze map en voer uit:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

De applicatie opent vervolgens automatisch in de webbrowser.

## Inhoud

- Equivalent-schema-model met dezelfde berekeningen als `main_V42.py`
- Dynamische resultaten voor stromen, spanningen, vermogens, koppel en rendement
- Simulatie en parameterbepaling via DC-, nullast- en kortsluitproef
- Interactieve koppel-, rendement- en power-factor-karakteristieken
- Automatische selectie van schema en meettoestel
